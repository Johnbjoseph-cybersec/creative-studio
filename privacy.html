Privacy Policy

Effective 22 October 2026

This policy explains how Creative Studio's internal publishing tool (the "Tool") handles data. The Tool is operated by Creative Studio solely to manage the studio's own channels: the YouTube channel The What-If House and the Instagram account Hair Science Co.

Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the Tool accesses

  • Basic information about the studio's own YouTube channel (channel ID, title, branding settings).
  • The studio's own videos and their metadata, which the Tool uploads and updates.
  • Aggregate performance statistics for the studio's own channel and account (views, watch time, audience retention, follower counts).
  • For Instagram: the studio's own account ID, its published media and its insights, through the Instagram API with Facebook Login.

The Tool does not access, collect or store personal data about viewers, commenters or any other users. Statistics are received only in aggregate form.

How the data is used

Data is used only to publish the studio's content and to measure how that content performs, so the studio can plan future content. It is never sold, never used for advertising profiles and never shared with third parties.

Storage and security

Access tokens are stored encrypted in the operating system's secure keychain on the studio's own computer and are never written to files, logs or third-party services. Aggregate statistics are stored locally on the same computer. Statistics older than 24 months are deleted.

Revoking access and deleting data

Access to a Google account can be revoked at any time on the Google security settings page. Access to an Instagram or Facebook account can be removed under Settings, Apps and Websites. To request deletion of any stored data, email ursjohn.joseph@gmail.com; stored data and tokens are deleted within 30 days of a request or of access being revoked.

Children

The Tool is not directed to children and does not knowingly process children's data.

Changes and contact

Changes to this policy are published on this page with a new effective date. Questions: ursjohn.joseph@gmail.com.
